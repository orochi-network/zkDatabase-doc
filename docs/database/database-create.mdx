# Create a Database

zkDatabase provides a simple way to create and manage databases with built-in zero-knowledge proof capabilities. Each database maintains a cryptographic state using Merkle trees, enabling provable data integrity.

Let's begin by exploring how to create a database.

### Example

<DatabaseExample
  code={`const dbTest = zkdb.db('zkdb_test');

// Check if database exists
const exists = (await dbTest.exist()).unwrapOr(false);

if (!exists) {
  (await dbTest.create()).unwrap();
  console.log('Database created');
} else {
  console.log('Database already exists');
}

// Get database info
const info = (await dbTest.info()).unwrap();
console.log('Database:', info.databaseName, 'Owner:', info.databaseOwner);`}
/>
