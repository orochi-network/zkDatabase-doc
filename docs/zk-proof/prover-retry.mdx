# Detect and retry failed operations

## Query for the current prover status

You can check the status of Merkle proof and ZK proof generation for your
database using the `proverStatus` method on an `IDatabase` object. This method
returns the current processing status of both operations. If either operation
fails, this method will return `Failed`.

### Definition

```ts
const status = (await zkdb.db(databaseName).proverStatus()).unwrap();
```

### Parameters
- None

### Returns

The operation returns a `Result` that resolves to the status of the prover
operations for your database. The status can be one of the following:

- `Queued`: There exists queued tasks ready to be processed.
- `Processing`: The prover is currently processing queued tasks.
- `Success`: The prover has successfully processed all queued tasks.
- `Failed`: There exists a failed task in the operation queue.
- `Unknown`: The queue's status cannot be determined.

### Example

<DatabaseExample
  code={`const dbTest = zkdb.db('zkdb_test');

// Get prover status
const proverStatus = (await dbTest.proverStatus()).unwrap();
console.log('Prover status:', proverStatus);`}
/>

## Retry failed operations

If the prover status returns `Failed`, you can retry the failed operation using
the `proverRetry` method on an `IDatabase` object. This method will attempt to
queue the failed operation for processing again.

### Definition

```ts
const retryResult = await zkdb.db(databaseName).proverRetry();
```

### Parameters
- None

### Returns

This method returns a `Result` that indicates whether the operation was
successfully queued for retry.

### Example

<DatabaseExample
  code={`

const dbTest = zkdb.db("zkdb_test");

// Get prover status first
const proverStatus = (await dbTest.proverStatus()).unwrap();

// Retry if failed
if (proverStatus === "Failed") {
    const retryResult = await dbTest.proverRetry();

    if (retryResult.isOk()) {
      console.log("Prover retried successfully.");
    } else {
      console.log("Prover retry failed:", retryResult.unwrapErr().message);
    }
}
`}
/>
